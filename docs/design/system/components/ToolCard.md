What the agent did on the Flipper, in the chat thread: a `surface-raised` card, the tool name in `mono` `accent-strong`, one sentence with what it did ('Pressed DOWN, DOWN, OK') and the screenshot it returned as a thumbnail on the orange LCD. `meta` holds the duration or the frame number. With `error` the card turns `danger-soft` and the text explains the failure as the server returned it. Screenshots are device data: they are shown, not interpreted in the card.
