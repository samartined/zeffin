The operator's two controls over the agent, always visible on Home, within thumb reach: Pause agent (filled `warning` button) and Resume (filled `success`), with black text. The consumer passes `state` and the component disables what does not apply: with the agent active, only Pause; paused, only Resume. They are never hidden. Starting and stopping the relay is not here: it lives in Settings, Relay. Interrupting the agent's turn is not here either: it is the conversation's send button, which shows a square while the agent is writing.
