A settings text field: label in `ink-muted` `caption` above, value in 16px over a `line-strong` bottom line that turns into a 2px `action` line on focus, hint in `caption`. `secret` hides the value (tokens); `mono` uses Roboto Mono (URLs, addresses). With `error` the line and the hint turn `danger` and the hint says what to fix. The consumer gives `label`, `value`, `placeholder` and, if any, `hint` or `error`.
