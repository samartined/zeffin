Filled pill button; the app has no outlined buttons. `primary` (`action` fill, black text) for the main action of the screen, one per screen: Copy diagnostics, Retry. `warning` and `success` (filled, black text) only for the agent controls: Pause and Resume. `small` is the 44px variant with 14px text for buttons inside a row, such as "Use" in the device list. `quiet` is blue text with no background. Disabled turns into a `line` fill. Secondary and destructive actions are not buttons: they are `ActionRow`s inside a card.
