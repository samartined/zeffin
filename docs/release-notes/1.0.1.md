## What's new since 1.0.0

### Fixes
- **`zf chat` no longer drops a connection now and then:** right after connecting, the server sent data that the terminal chat could trip over, and the connection sometimes closed before the chat opened. The server no longer sends it. The app was not affected.
- **Every connection shows the server's key:** the server no longer lets a connection resume an earlier encrypted session, so the app and `zf chat` check the pinned key every time they connect.

### Updating
- **Update the server** with `zf update`, then install app 1.0.1 from this release. The app itself has no changes in this version: installing it keeps the two version numbers together.
