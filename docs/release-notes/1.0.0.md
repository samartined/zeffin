## Zeffin 1.0.0, the first public release

Zeffin lets an AI agent drive your Flipper Zero from anywhere, with your Android phone as the bridge. The agent runs on a Linux server of your own; you talk to it from the Zeffin app, watch the Flipper's screen live and pause it at any moment. The app and the server share one version number: install server 1.0.0 with app 1.0.0.

### Getting started
- **Install the server with one script:** clone the repository and run `install.sh`. It checks what it needs, installs the server and its service, sets up the agents it finds and ends with the pairing QR code. It never uses `sudo` and never prints a token, and running it again is safe.
- **Pair the app:** install the APK from this release on the phone, scan the QR code and confirm on the server. The app then reaches your server only through Tailscale, with the server's key pinned.
- **A user's guide** in `docs/guide/`: install, pair, use the agent, the Flipper tools, the remote, Pause and Stop, security, updating, the `zf` command, troubleshooting and the FAQ.

### The agent drives the Flipper
- **Like a person with a remote:** it looks at the screen, presses keys and looks again, so it reaches any app or menu. It also has tools for files, apps and any RPC request.
- **It knows the firmware:** it detects which firmware the Flipper runs and which apps it has, with a line about each.
- **It can keep a note on how to drive an app:** after it works out an app with a hidden key or an odd exit, it can save a short note, by itself or when you ask; later conversations on your server start from it. `zf notes` lists, shows and deletes the notes, and `zf notes off` turns them off.

### Two agents, your choice
- **Claude Code or OpenCode,** chosen per conversation. Each keeps its own model, effort and permission mode.
- **Paid or free is up to you:** each agent runs with the login or providers you set up on the server. A model that may bill says "Paid" in the models' list.
- **Free options:** Claude Code with a subscription you already have, and OpenCode on NVIDIA NIM's free tier (a free NVIDIA account, no card) or OpenCode Zen's free models (no account). The "free only" switch (`zf set-free-only on`) keeps Zeffin to those.
- **Free providers keep what they receive** to improve their models, the Flipper's data included. Keep that in mind before you read NFC or RFID dumps with them.
- **A model that takes few images keeps working:** before a conversation goes past the model's limit of screens, Zeffin has the agent summarize it, and the conversation says so.
- `zf status` shows both agents: versions, logins and providers. `zf agent setup` sets each one up.

### You stay in control
- **The live screen** in the app and in a web view, and every action of the agent as it happens and in an audit log.
- **Pause** leaves the agent only able to read; **Stop relay** closes the phone's session until you resume.
- **Permission cards show the whole request:** the file or command first, then every argument under its own label. Long ones scroll; one too long to show whole can only be denied.
- **The agents cannot change their own settings without asking:** an edit of their instructions or configuration files always shows its card, also in Accept edits and after "Always".
- **The remote:** drive the Flipper yourself from the app. Opening it pauses the agent.
- **`zf status` lists the devices that use your server:** each one's name on your tailnet, what it used and whether it is connected now.

### In the app
- **Conversations** with models, effort and permission modes, attachments (photos, files, the Flipper's screen) and notifications. Select several with a long press to pin, favorite or delete them together.
- **Settings, Connections, Agents:** each agent's state, version and login. An agent that is not ready says why and what to run on the server.
- **Zeffin's character:** a small face that shows the state at a glance (working, writing, asking, paused, offline). It stays still with Android's "Remove animations".
- **In English and Spanish,** following the phone's language, or set in Settings, Language.
- You can also talk to the agent from a terminal on the server, with `zf chat`.
