# Zeffin user's guide

How to set up Zeffin and use it: an AI agent that drives a Flipper Zero through an Android phone, from a server of your own.

1. [What Zeffin is and what it needs](what-is-zeffin.md): the pieces, how they connect, and the requirements.
2. [Install the server](install-the-server.md): the server, its folders, the Tailscale policy and the web view.
3. [Pair the app](pair-the-app.md): install the app, connect Tailscale, pair with the server and connect the Flipper.
4. [Use the agent](use-the-agent.md): Claude Code or OpenCode, setting them up, what each agent uses, what free providers keep, conversations, models, effort, permission modes, permissions, attachments, notifications, Remote Control and `zf chat`.
5. [The Flipper tools](flipper-tools.md): what the agent can do with the Flipper, and what it reads.
6. [The remote](the-remote.md): drive the Flipper yourself from the phone.
7. [Pause and Stop](pause-and-stop.md): the operator's gate.
8. [Security](security.md): what is trusted, the pinned key, the private network, and what Zeffin does not stop.
9. [Updating](updating.md): the server, the app, the tokens and the key.
10. [The `zf` command](zf-command.md): every command on the server.
11. [Troubleshooting](troubleshooting.md): the messages you may see, and what to do.
12. [FAQ](faq.md).

The reference documents (the architecture, the security model, the protocols, the design) are listed in the [documentation index](../README.md).
